# Tools Library

This folder preserves the original ML/AI material from the repository and acts as the source library for the main AI analysis app.

Highlights:

- `python/`: operational ML utilities for anomaly detection, clustering, forecasting, and LLM experiments
- `java/`: Flink and XGBoost integration references
- topic folders such as `anomaly-detection/`, `fraud-detection/`, and `time-series-prediction/`: supporting notes and assets

The main app in `frontend/` and `backend/` exposes these capabilities as selectable analysis tools for uploaded datasets.
